# ReguAI - Enhanced UI & Visualization: Technical Specification

---

## 1. Executive Summary

**ReguAI** is a next-generation, client-side Single Page Application (SPA) focused on demystifying medical device regulatory analysis through deep AI-powered visualization, immersive user interfaces, and modular agent workflows. Powered by Google Gemini 3 Flash Preview (with future extensibility to OpenAI), ReguAI transforms complex FDA 510(k), PMA, and international dossiers into actionable, structured, and visually-arresting regulatory intelligence.

This technical specification details the enhanced ReguAI system—featuring a new “WOW” UI experience with adjustable painter-inspired themes, interactive dashboards, customizable agentic workflows, and AI-enabled note-taking. It is deployable via Streamlit on Hugging Face Spaces, and integrates seamlessly with Gemini and OpenAI APIs, using `agents.yaml` and `SKILL.md` to define extensible agent capabilities and system prompts.

---

## 2. System Architecture

### 2.1. High-Level Overview

- **Frontend Framework:** React 18 + TypeScript, built with Vite for lightning-fast builds and HMR.
- **WOW Layer:** Visualization and theming powered by Tailwind CSS 4, Recharts, and on-the-fly style composition.
- **Agent-Orchestration:** Modular agent workloads defined in `agents.yaml`, with skill context in `SKILL.md`.
- **API Service:** Gemini and OpenAI API integration in a unified service layer; agent and model selection with environment-aware API key management.
- **Deployment:** Streamlit-based UI deployed in Hugging Face Space.

### 2.2. Multimodal UI/UX

- **Theming:** Light/dark modes, 20 famous painter themes (e.g., Van Gogh, Monet, Hokusai), with “Jackpot” randomizer.
- **Languages:** Full English/Traditional Chinese localization, extensible to other markets.
- **Visualization:** State-of-the-art “WOW Status Indicators,” animated, color-coded, responsive dashboards, and rich charts.

## 4. Core Feature Modules

### 4.1. Dynamic Theming and Painter Styles

- **Modes:** Light/Dark toggle, supporting system/user preference reactivity.
- **Painter-Theme Palette:** 20 selectable palettes, each reflecting the style of a master painter (e.g., Van Gogh–vivid yellow/blue, Monet–soothing pastels, Picasso–abstract contrasts).
- **Jackpot Mode:** “Surprise me” randomizer button for serendipitous theme discovery.
- **Live Preview:** Real-time theme transitions; visual indicators for active style.
- **Accessibility:** All themes tested for high color contrast/compliance.

#### Technical Implementation

- **CSS Variables:** Root-level variables for palette definitions; theme class applied to `<body>` or root component.
- **Theme Metadata:** JSON/TypeScript definitions for painter meta (color swatches, css overrides, biography tooltip).
- **Persistent Selection:** Theme preference stored in `localStorage` or via broader user-settings context.

### 4.2. Internationalization & Localization

- **Languages Supported:** English & Traditional Chinese with language toggle in header.
- **Extensibility:** I18n resource files modularized for adding new regulatory locales (e.g., Japanese, German).
- **Bidirectional UI:** Adjusts chart/flow direction for CJK scripts as needed.

### 4.3. API Key Management

- **Dynamic Key Provisioning:** User prompted to input API key if not found in environment (e.g., build-time env or server-injected secure config).
- **Client-Side Masking:** If API key is provisioned by environment, UI does not expose key edit field.
- **User Feedback:** Status indicator (e.g., green light with “Key Verified” vs. red cross with “Missing Key”) and copy-paste prevention for environment-injected keys.
- **Key Validation:** Lightweight client validation before API calls (length, prefix).

### 4.4. Model & Agent Selection/Chaining

- **Supported Models:** User dropdown for `gpt-4o-mini`, `gpt-4.1-mini`, `gemini-2.5-flash`, `gemini-2.5-flash-lite`, `gemini-3-flash-preview` (default), and other future models.
- **Agentic Workflow:** User selects/edits model per agent step, with explicit “Execute Next Agent” UI trigger.
- **Prompt Editability:** Inline editable prompts, with pre-execution syntax validation and helpful hints.
- **Output as Next Input:** Partial output can be tweaked (in text or markdown view) and piped as input to subsequent agents, forming modular, explainable pipelines.
- **Model Metadata:** Full model details (e.g., max tokens, rate limits, latency) accessible as tooltips.

### 4.5. AI-Powered Note Keeper (WOW Feature)

- **Paste & Transform:** Users paste unstructured text or markdown; AI transforms into organized markdown outline (e.g., headings, bulleted lists, tables).
- **Editable Views:** Toggle between WYSIWYG markdown editor and plaintext editor.
- **Prompt-to-Note Linking:** User can pin/save the original transformation prompt with the note for traceability.
- **Model Selection:** Supported models selectable for note transformation.
- **AI Magics Suite:**
    1. **AI Formatting:** Auto-enhances markdown structure (table of contents, auto-numbering, summary snippets).
    2. **AI Keywords:** Highlights key terms (user customizes highlight colors), generates tag-list and auto-index.
    3. **AI Summarization:** On-click summary of pasted text.
    4. **AI Q&A:** Generates FAQ list from note contents.
    5. **AI Topics Extraction:** Pulls concepts/taxonomies.
    6. **AI Reference Linking:** Cross-links regulatory references or standards.

- **History Maintenance:** Undo/redo for note edits, with revision slider.

## 5. WOW Visualization Features

### 5.1. WOW Status Indicators

- **Live Progress:** Loading bars and spinners visually themed to selected painter; progress mapped to backend state (e.g., topic completion, checklist ingestion).
- **Multi-agent Status:** Each agent displays unique emblem and live status: queued, running, succeeded, warning, or failed—with color semantics and tooltips.
- **Health Bar:** System-wide health (API latency, rate, token usage) visualized as animated bar or color-changing icon.
- **Toast Notifications:** Contextual feedback for errors (“JSON Repair triggered”), successes, or important agent transitions.

### 5.2. Interactive Dashboard

Tab-based or card-based (user toggles layout):

- **Infographics:** Interactive, filterable visual tiles for each regulatory topic, expandable for detail.
- **Checklist:** Accordion or progressive-table for 100-point checks; items crossed off by user as “reviewed.”
- **Regulatory Risk Radar:** Animated radar/polar chart (Recharts), with real-time highlighting per risk category; points clickable for in-depth reasoning.
- **SE Matrix:** Responsive comparison table; color-coded badges (identical/similar/different); click cell for AI “justification.”
- **FDA Deficiency Letter:** Modeled as stylized letter, with track-changes display for “resolved” findings.
- **Prompt Data Tracing:** Visual map of agent input/output flow.
- **User Edits:** All outputs are editable; changes reflected in next agent inputs and final export.

## 6. Core Data Models

All UI and agent workflows conform to these models (TypeScript-like):

- **AppState:** System-wide state, storing theme, painterStyle, language, step, all AI outputs, current API/model keys, process indicators, and error flags.
- **ThemeMeta:** { id, displayName, primaryColor, accentColors[], patternSVG, artistInfo }
- **AgentRun:** { agentId, name, model, parameters, prompt, output, status, updatedAt }
- **Note:** { id, rawText, markdown, prompt, modelUsed, transformations[], history[] }
